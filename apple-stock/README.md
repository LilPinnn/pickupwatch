# Pickup Watch

หน้าเว็บเดียว แสดงสถานะสต็อก "พร้อมรับที่สาขา" ของ Apple Store Thailand
- รีเฟรชได้ 2 แบบ: กดปุ่ม หรือเปิด Auto ให้ดึงข้อมูลใหม่ทุก 30 วินาที
- ไม่มีการเชื่อมต่อ LINE หรือ Google Sheet — เป็นหน้าดูสถานะอย่างเดียว
- การดึงข้อมูลจาก Apple ทำฝั่งเซิร์ฟเวอร์ (API Route) เพื่อเลี่ยงปัญหา CORS

## แก้รุ่น / สาขาที่ติดตาม

แก้ที่ `app/api/stock/route.ts` ด้านบนไฟล์:

```ts
const STORES = ['R733', 'R728'];        // รหัสสาขา
const PRODUCTS = ['MJXQ4ZP/A', ...];    // part number ที่ต้องการติดตาม
```

## รันทดสอบในเครื่อง

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## Deploy ขึ้น Vercel

ทางที่ง่ายที่สุด:

1. Push โฟลเดอร์นี้ขึ้น GitHub repo (ใหม่)
2. ไปที่ https://vercel.com/new แล้วเลือก import repo นั้น
3. Vercel จะ detect เป็น Next.js อัตโนมัติ กด Deploy ได้เลย ไม่ต้องตั้งค่า environment variable ใดๆ

หรือใช้ Vercel CLI จากเครื่อง:

```bash
npm i -g vercel
vercel
```

## ข้อควรรู้

- ฝั่งเซิร์ฟเวอร์ยิง request ไปที่ `apple.com` แบบขนานทุกครั้งที่มีคนรีเฟรชหน้า (หรือทุก 30 วิถ้าเปิด Auto และมีคนเปิดหน้าค้างไว้) หากมีคนเปิดหน้าทิ้งไว้หลายคนพร้อมกัน ความถี่ในการยิงจริงจะเพิ่มตามจำนวนคนที่เปิดหน้าอยู่
- Apple อาจ rate-limit หรือบล็อก IP ที่ยิงถี่เกินไป (ความเสี่ยงนี้มีอยู่แล้วไม่ว่าจะรันจากที่ไหน) ถ้าพบ error บ่อยให้ลดความถี่หรือปิด Auto
- ปัจจุบันไม่มีการเก็บ log ประวัติสต็อกไว้ที่ไหน — หน้านี้แสดงเฉพาะสถานะล่าสุด ณ ตอนนั้น
